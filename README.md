# Лабораторна №14 — Bootstrap
Завдання 1: `task1.html` — сім блоків з адаптивним порядком і кольорами відповідно до зразка.
Завдання 2: `task2.html` — три колонки з розмірами XL 6/3/3, LG 8/4/12, MD та менше — 12/12/12.
Контрольні ширини: 1200+, 992–1199, 768–991, до 767 px. Bootstrap завантажується з CDN, тому для повноцінного вигляду потрібен інтернет.
Додаткове завдання: `npm install`, `npm start`; адреси `/task1` та `/task2`.
Запуск Express у цьому середовищі не підтверджено.
